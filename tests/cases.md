# Scoring reference cases

Run these cases with `python -B -m unittest discover -s tests -v` from the repository root. Expected scores were calculated by hand from the published rubric; they are not generated by the test evaluator.

Q6 contains only confirmed letters. `-` means no confirmed tags. Detected constraints and free text are not scoring inputs. Each row checks a candidate's score, not whether it wins its dimension or should be adopted.
